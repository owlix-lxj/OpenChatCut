# HeyGen 自定义数字人形象

这是 AI-cut 内置的数字人形象工作流。能力由平台后端调用 HeyGen，客户端不保存 HeyGen API Key，也不要求用户安装 CLI、MCP 或第三方插件。

## 工作原则

1. 只使用用户自己创建并有权使用的数字人形象，不推荐、展示或自动替换为 HeyGen 公共数字人。
2. 创建真人照片数字人前，必须取得用户对肖像创建与使用的明确授权确认。上传照片本身不等于授权。
3. 原始照片从本地素材池选择；只有用户确认创建后，平台后端才会将必要素材上传到云端服务。
4. 不在对话、日志或项目文件中显示 API Key、供应商请求体、内部任务 ID 或签名信息。
5. 创建结果进入“数字人形象库”。只有状态为已就绪的形象才能作为课程视频的主讲人。

## 执行流程

1. 确认用户要创建的是本人或已获授权人物的定制形象。
2. 引导用户在“数字人智能制课”面板上传 JPG/PNG 正面清晰照片，填写形象名称并勾选肖像授权。
3. 提交后说明创建发生在云端，并等待形象状态变为已就绪；失败时展示可操作的失败原因并允许刷新或重试。
4. 创建成功后，在形象库中选中该形象。选择应持久化到当前课程任务，但不能静默替换用户先前选择。
5. 若用户要求删除，先确认具体形象，再从平台形象库删除；不要删除本地原始照片素材。

## 与其他技能衔接

- 用户要用已选数字人生成课程视频时，继续使用 `heygen-video`。
- 用户要翻译已经完成的视频时，使用 `heygen-translate`。
- 用户只是需要普通配音或本地剪辑时，不启动本技能。

## 完成标准

必须能确认形象已进入用户自己的数字人形象库，并且状态可用于后续课程生成。若云端尚未完成，只报告当前状态和下一步，不宣称已经可用。
