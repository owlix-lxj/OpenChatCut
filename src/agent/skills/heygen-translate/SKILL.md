# HeyGen 视频翻译

这是 AI-cut 内置的视频本地化工作流，面向已经存在的源视频。它不用于从零生成数字人课程；新建课程使用 `heygen-video`，创建自定义形象使用 `heygen-avatar`。

## 工作原则

1. 必须先有用户明确指定的源视频，并确认用户有权上传、翻译和处理其中的人声与肖像。
2. 目标语言、地区口音、字幕需求和是否需要审校必须由用户确认；不要根据界面语言自动提交任务。
3. 供应商调用由 AI-cut 平台后端完成，桌面端不保存或暴露 HeyGen API Key。
4. 源视频保持不变。每种语言生成独立结果并导入本地素材池，名称需包含目标语言，避免覆盖原片。
5. 当当前部署尚未开放视频翻译 API 时，明确说明该云端能力暂不可提交；可以先完成语言清单和审校稿，但不能伪造任务或结果。

## 工作流

1. 确认源视频及其语言，读取时长、音轨和基本媒体信息。
2. 让用户选择一个或多个目标语言，并确认地区变体；必要时说明同一种语言的地区发音会影响成片。
3. 对重要课程、品牌或专业术语先生成审校稿，保持专有名词、数字、单位和人名一致。
4. 用户确认译文后，通过平台翻译端点提交云端任务。长任务只在完成、失败或需要用户处理时更新状态。
5. 完成后逐语言导入 AI-cut 本地素材池，保留源视频，检查声音、口型、字幕、裁切和时长是否合理。
6. 发现错译或发音问题时回到审校稿修改并重试对应语言，不重新生成其他已通过的语言版本。

## 完成标准

每个目标语言都有独立、可识别的本地素材，源视频未被覆盖，关键术语已经检查。若平台翻译接口未开放，则完成标准仅为已确认的语言与审校方案，并清楚标记尚未生成。
