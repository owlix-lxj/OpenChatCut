# HeyGen 数字人智能制课

这是 AI-cut 内置的云端数字人课程工作流。用户在 AI-cut 中编排课程，平台后端负责调用 HeyGen；桌面客户端不接触供应商密钥，也不要求安装任何外部工具。

## 硬性约束

1. 课程视频只使用用户在“数字人形象库”中明确选择且状态为已就绪的自定义数字人。
2. 不展示、不推荐、不自动使用 HeyGen 平台公共形象；没有可用自定义形象时必须先完成 `heygen-avatar`。
3. 课程配音必须来自面板中可试听的声音列表。用户试听并选择后，生成任务始终使用该 voice id，不能静默更换。
4. 云端调用全部通过 AI-cut 平台 API。不得把 HeyGen API Key 写进桌面 App、技能文件、日志或项目。
5. 成片完成后导入 AI-cut 本地素材池，后续剪辑与项目保存继续遵循本地优先原则。

## 工作流

1. 读取课程主题、目标受众、学习目标和用户提供的文档或讲稿。
2. 先生成可独立审阅的课程讲稿，按知识点拆成短小、自然的段落；保留用户确认前的可编辑状态。
3. 确认数字人形象库中已选择一个可用形象；没有时停止生成并引导用户创建。
4. 展示课程配音模块，允许按语言、性别和名称筛选并试听。用户明确选择一个声音。
5. 为每段生成标题、讲稿与预计时长，检查空段、重复段、过长句和读音歧义。
6. 用户确认后提交一次云端生成任务。生成期间刷新任务状态，失败时保留讲稿、形象和声音选择以便重试。
7. 每个完成片段都应能导入本地素材池；导入后可继续排版、加字幕、配乐、转场和导出。

## 交互要求

- 用自然语言报告“正在生成”“已完成”“需要重试”，不倾倒供应商任务字段。
- 不显示内部预留金额、结算秒数或空账单模块，除非产品未来明确开放账单页。
- 若用户只要求先写讲稿，则只生成讲稿，不提前提交视频。
- 若形象或声音失效，要求重新选择，不回退到公共默认值。

## 完成标准

课程讲稿已确认、用户自定义数字人与声音选择明确、云端任务成功完成，并且成片已导入本地素材池。只完成其中一部分时，应准确说明当前阶段。
